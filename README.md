# readiverse

在自己電腦上跑的英文閱讀室：匯入書的 PDF，分類整理，左邊讀英文、右邊寫筆記。

- **首頁**：像串流影音那樣，上方大看板放最近在讀的書，下面一排一排橫向捲動：繼續閱讀、最近加入、我的最愛、每個分類、讀完。滑到書上會放大，直接按 ▶ 讀、☆ 加最愛、⋯ 改資料。右上角可以切換卡片／清單模式；頭像點開是使用者資訊和設定。匯入 PDF 可以一次選好幾本，或直接拖進視窗；書可以拖到分類那一排換分類。每張卡片都有封面、書名、作者：第一頁像封面的就用第一頁，第一頁是滿滿文字的就自動做一張「書名＋作者」的封面；在「詳細資料」可以換成自己的圖片或 PDF 的任何一頁。預設淺色模式。
- **解析 PDF**：匯入時先用 pdf.js 幾秒內抽出文字，馬上能讀；接著 [Docling](https://github.com/docling-project/docling)（IBM 開源的版面解析）在背景一頁一頁升級：分段更準、圖片和表格截下來放回原位、頁首頁尾拿掉。程式碼再補上清理：重複的頁首、OCR 雜訊（`----=---~->`）、跨頁斷字（ex- / pected）、圖表旁的碎字、被改掉的破折號。畫過螢光筆、寫過筆記、翻譯過的頁不會被動到。
- **AI**：匯入時只問一次，自動填書名、作者、分類、標籤，並挑出哪一頁是封面；你在「詳細資料」改過的欄位不會被蓋掉。哪一頁排版或 OCR 錯字怪怪的，按該頁的 ✦「用 AI 整理這一頁」。
- **閱讀**：左邊大約 72% 是英文，一頁一頁翻（← → 鍵也可以）；也能切換回原始 PDF 頁面。按「中文」會在每段英文底下顯示 AI 翻譯，中文可以直接點進去改。
- **筆記**：選取文字就能畫螢光筆（四種顏色），也可以加筆記、複製、查劍橋字典。有寫筆記的才會出現在那一段的右邊（單純的螢光筆只留在內文），滑到段落上會出現「＋ 筆記」；每一段、每一頁也都可以寫自己的筆記。「全書筆記」可以篩選顏色，也能匯出成 Markdown。
- **雲端同步**：書庫可以放進 Google 雲端硬碟或 OneDrive 的同步資料夾，換電腦打開就是同一份書和筆記。

## 開始使用（Mac）

1. 雙擊 `開啟Readiverse.command`，瀏覽器會打開 <http://localhost:8780>。
2. 看書的時候，這個黑色視窗要開著。

需要 Python 3.9 以上的版本（Mac 內建就有，不用另外裝套件）。PDF 是用 [pdf.js](https://mozilla.github.io/pdf.js/) 在瀏覽器裡讀的，第一次打開需要網路。

## Docling（版面解析）

第一次打開時會自動在 `~/.readiverse/docling-venv` 建一個 Python 3.12 環境並安裝 Docling（約 2 GB，要幾分鐘；有 [uv](https://github.com/astral-sh/uv) 會快很多）。安裝紀錄在 `~/.readiverse/docling-install.log`，設定裡可以看狀態、重新安裝。裝不起來也沒關係，只是少了圖表截圖和更準的分段。

## AI 翻譯／整理

AI 用的是你電腦上已經登入的 **Claude Code**（`claude`）。Claude 不能用時，會自動改用 **Codex**（`codex`）。兩個都沒有的話，閱讀和筆記照樣能用，只是沒有翻譯和自動整理。

- Claude 登入過期：在終端機輸入 `claude` 重新登入。

## 資料放在哪裡

預設放在專案裡的 `書庫/` 資料夾（不會上傳到 GitHub）。到「設定 → 書庫存放位置」可以換到 Google 雲端硬碟或 OneDrive，換的時候原本的資料夾會留著當備份。書庫位置記在 `~/.readiverse.json`。

```
書庫/
  _index.json            書的清單、分類、名字
  <id>/book.pdf          原始 PDF
  <id>/cover.jpg         封面
  <id>/pages.json        每一頁的段落；圖片、表格是 {"t":"fig"/"table", ...}
  <id>/pages_raw.json    pdf.js 抽出來的原始段落
  <id>/figs/             Docling 截下來的圖片、表格
  <id>/state.json        螢光筆、筆記、中文翻譯
```
