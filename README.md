# readiverse

在自己電腦上跑的英文閱讀室：匯入書的 PDF，分類整理，左邊讀英文、右邊寫筆記。

- **首頁**：像串流影音那樣，上方大看板放最近在讀的書，下面一排一排橫向捲動：繼續閱讀、最近加入、我的最愛、每個分類、讀完。滑到書上會放大，直接按 ▶ 讀、☆ 加最愛、⋯ 改資料。右上角可以切換卡片／清單模式；頭像點開是使用者資訊和設定。匯入 PDF 可以一次選好幾本，或直接拖進視窗；書可以拖到分類那一排換分類。每張卡片都有封面、書名、作者：第一頁像封面的就用第一頁，第一頁是滿滿文字的就自動做一張「書名＋作者」的封面；在「詳細資料」可以換成自己的圖片或 PDF 的任何一頁。預設淺色模式。
- **解析 PDF**：匯入時先用 pdf.js 幾秒內抽出文字，馬上能讀；接著在背景升級。**掃描書**（整頁是圖片的）不用 PDF 裡原本那層常常很爛的 OCR 文字，改用 Mac 內建的 Apple Vision 重新辨識，再依縮排、行距自己分段；之後自動檢查每頁的亂碼比例，太高的頁（每本最多 20 頁）交給 AI 修正，其餘頁碼旁邊顯示 ⚠。**數位書**用 [Docling](https://github.com/docling-project/docling)（IBM 開源的版面解析）：分段更準、圖片和表格截下來放回原位、頁首頁尾拿掉。程式碼再補上清理：重複的頁首、OCR 雜訊（`----=---~->`）、跨頁斷字（ex- / pected）、圖表旁的碎字、被改掉的破折號。畫過螢光筆、寫過筆記、翻譯過的頁不會被動到。
- **AI**：匯入時只問一次，自動填書名、作者、分類、標籤，並挑出哪一頁是封面；你在「詳細資料」改過的欄位不會被蓋掉。哪一頁排版或 OCR 錯字怪怪的，按該頁的 ✦「用 AI 整理這一頁」。
- **閱讀**：排得像一本書：首行縮排、左右對齊、英文斷字、章名置中加首字放大、上方書眉（書名）、下方頁碼；段落不會斷在兩頁。左邊大約 72% 是英文，一個畫面一頁、不用上下捲動：一頁放不下就自動分成好幾個畫面（頁碼旁邊顯示 1/2、2/2），很長的段落在行與行之間接到下一個畫面；圖和表格自己一個畫面、放大到剛好填滿；放大縮小字時正在讀的段落留在最上面；會記住看到哪一頁、哪個畫面，上下都有 Previous / Next（← → 鍵、空白鍵也可以）；也能切換回原始 PDF 頁面。按「中文」會在每段英文底下顯示 AI 翻譯，中文可以直接點進去改。
- **筆記**：選取文字就能畫螢光筆（四種顏色），也可以加筆記、複製、查劍橋字典。每一段右邊直接就是筆記格子，點進去打字就會存；螢光筆有寫筆記的也會出現在那一段的右邊（單純的螢光筆只留在內文）。「全書筆記」可以篩選顏色，也能匯出成 Markdown。
- **字典**：選一個字按 📖 查字典，顯示中文（本機 ECDICT 字典，40 萬字、離線）、音標、發音、英英解釋和例句（[Free Dictionary API](https://dictionaryapi.dev/)，免費、不用金鑰），還能按「AI 解釋」看這個字在這一句裡的意思。劍橋字典目前會擋自動連線，擋住時會自動跳過。
- **單字收藏 ◆、句子收藏 ✦**（跟雅思練習室一樣）：收藏的單字在所有書裡都會畫青綠色底線，收藏的句子由 AI 整理出片語、句型、中文、例句，出現同樣句型的地方會畫紫色底線（時態、複數、sth/sb 這類空格都認得）。點底線就會跳出卡片：意思、收藏時的句子、出處、加入複習、刪除。首頁上方兩個 icon 進入「我的字典」和「句子收藏」頁，頁面上的 ⤓ 可以匯入收藏（重複的不會再加）。
- **雲端同步**：書庫可以放進 Google 雲端硬碟或 OneDrive 的同步資料夾，換電腦打開就是同一份書和筆記。

## 開始使用（Mac）

**用 App（建議）**：雙擊桌面上的 `Readiverse.app`，用自己的視窗打開（跟雅思練習室一樣，Dock 上會顯示 Readiverse，關掉視窗就結束）。

第一次做 App，或程式更新之後，在程式資料夾執行：

```bash
bash tools/make_mac_app.sh
```

它會用 PyInstaller（自動用 uv 建一個 Python 3.12 打包環境，裝 pywebview）把程式包成 `~/Desktop/Readiverse.app`；沒有 uv 的話會做一個用電腦上 python3 執行的簡單版 App。

**不做 App**：雙擊程式資料夾裡的 `開啟Readiverse.command`（加 `--browser` 改用瀏覽器）。

> macOS 不讓 App 讀「桌面」「文件」「下載」資料夾裡的檔案，所以程式會複製一份進 App，書和筆記放在使用者資料夾的 `~/Readiverse書庫`。

PDF 是用 [pdf.js](https://mozilla.github.io/pdf.js/) 讀的，第一次打開需要網路。

## 匯入 PDF 的流程

1. **pdf.js 先抽文字**（幾秒）→ 馬上可以讀
2. **判斷是掃描書還是數位書**（抽樣幾頁：整頁是一張圖＝掃描書）
   - **掃描書**：用 Mac 內建的 Apple Vision 一頁一頁重新辨識（不用 PDF 裡原本那層常常很爛的 OCR 文字），依縮排、行距、字的大小分段；字比內文大的是章名，最上面的小字是頁首（丟掉），頁碼丟掉
   - **數位書**：用 Docling 解析版面，圖片、表格截下來
3. **程式碼清理**：重複的頁首頁尾、花紋和項目符號被認成的雜訊（* • « me ace）、跨頁的段落接回同一頁、被切斷的句子接起來、被圖表切斷的句子接起來、軟連字號、破折號
4. **品質檢查**（掃描書）：每頁算「字典裡查不到的字」的比例，太高的頁自動交給 AI 修正（每本最多 20 頁），其餘頁顯示 ⚠，可以按 ✦ 修
5. **AI 判斷書名、作者、分類、標籤、封面**（只問一次）

畫過螢光筆、寫過筆記、翻譯過的頁，重新解析時不會被動到。

### 測試流程

改了解析規則之後，用幾本不同類型的 PDF 跑一次，會自動檢查亂碼、段落開頭雜訊、殘留頁首、跨頁沒接上、句子被切斷、超長段落：

```bash
~/.readiverse/docling-venv/bin/python tools/pipeline_test.py 書1.pdf 書2.pdf --pages 1-60
```

## Docling（版面解析）

第一次打開時會自動在 `~/.readiverse/docling-venv` 建一個 Python 3.12 環境並安裝 Docling（約 2 GB，要幾分鐘；有 [uv](https://github.com/astral-sh/uv) 會快很多）。安裝紀錄在 `~/.readiverse/docling-install.log`，設定裡可以看狀態、重新安裝。裝不起來也沒關係，只是少了圖表截圖和更準的分段。

## AI 翻譯／整理

AI 只用你電腦上已經登入的 **Claude Code**（`claude`）。沒有登入的話，閱讀、筆記、解析照樣能用，只是沒有翻譯、書名判斷和 AI 校對。

- Claude 登入過期：在終端機輸入 `claude`，再輸入 `/login` 重新登入。

## 資料放在哪裡

預設放在 `~/Readiverse書庫`（使用者資料夾，不在 GitHub 上）。到「設定 → 書庫存放位置」可以換到 Google 雲端硬碟或 OneDrive，換的時候原本的資料夾會留著當備份。書庫位置記在 `~/.readiverse.json`。

```
書庫/
  _index.json            書的清單、分類、名字
  <id>/book.pdf          原始 PDF
  <id>/cover.jpg         封面
  <id>/pages.json        每一頁的段落；圖片、表格是 {"t":"fig"/"table", ...}
  <id>/pages_raw.json    pdf.js 抽出來的原始段落
  <id>/figs/             Docling 截下來的圖片、表格
  <id>/state.json        螢光筆、筆記、中文翻譯
  _單字收藏.json / _句子收藏.json / _字典快取.json   字典和收藏
```

## Windows 版

跟雅思練習室一樣用 GitHub Actions 打包（`.github/workflows/build-windows.yml`）：

```bash
git tag v0.1.0 && git push origin v0.1.0
```

推上 `v*` 版號後，GitHub 的 Windows 電腦會：PyInstaller 打包成 `Readiverse.exe` → 自動測試 → Inno Setup 做成 `Readiverse-Setup.exe` → 測安裝／解除安裝 → 發佈到這個倉庫的 Releases。

- 安裝在「使用者\AppData\Local\Programs\Readiverse」，不用管理員權限；書庫在「使用者\Readiverse書庫」或設定裡選的 Google 雲端硬碟／OneDrive，更新、解除安裝都不會動到。
- AI 用 Windows 上的 Claude Code（`claude.exe` 或 npm 裝的 `claude.cmd` 都可以），設定裡一樣可以直接登入（用 pywinpty）。
- 版面解析：第一次用時自動裝 uv 和 Docling；掃描書在 Windows 用 Docling 內建的 OCR（Mac 用 Apple Vision）。
- 從原始碼執行：雙擊 `開啟Readiverse.bat`。

## AI 校對（抽樣）

每 5 頁抽 1 頁給 Claude 對照原書校對，加上程式覺得可疑的頁（漏字、亂碼）；抽到的頁有修正，就把前後各 2 頁也校對。
